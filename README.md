# Fundamentals of Computer Science — Student Materials

This course builds a practical mental model of how a computer represents data,
executes programs, and provides system services. Python is used to connect each
model to observable behavior.

It is designed for first-year college/university students and assumes no prior
programming experience. The complete course contains 40 hours of short video
lectures and 60 hours of paired in-class exercises. Python is taught from the
beginning.

The course was designed as a complete learning path before individual lecture
production began. Each final release contains notes, exercises, separate worked
solutions, code, captions, and links to the video lecture.
